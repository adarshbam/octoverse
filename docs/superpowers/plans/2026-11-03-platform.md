# OctoVerse Platform (I01 + I02 + J01) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the OctoVerse platform on the extracted engine: the host octopus and its reef, the landing (entrance, intro, How It Works), explore, showcase profiles, world visits with shareable routes and exact history, and the local creator with a live preview.

**Architecture:** The host is a `WorldBundle` (`octoverse`) under `src/worlds/octoverse/` with assets under `public/octoverse/` and `blender/reef/`, built from variants the worlds already added. The platform is an HTML layer in `src/platform/` that mounts at most one engine page instance and one preview instance at a time through the A2 host options (`ui: 'none'`, `useInstanceApi`, `PreviewOptions`, `initialStage`, `onStageChange`, `stageRequest`, `exit`, `attend`). The creator assembles creator bundles from world templates and presets. The platform never edits engine or world code; a gap goes to the engine owner.

**Tech Stack:** React 19, TypeScript, three 0.186.1, R3F 9, drei 10, postprocessing 3, Theatre.js 0.7.2, Vite 8, Vitest, Playwright (Edge), Python (Pillow, numpy) check tools, Blender headless. No new runtime dependency.

**Spec:** `docs/superpowers/specs/2026-11-03-platform-3d-design.md` (cited as "spec 7.9" and so on). Also read the engine contract `docs/superpowers/specs/2026-11-03-octoverse-engine-design.md` ("contract 19"; A2 is final) and the E02 plan `docs/superpowers/plans/2026-11-03-engine-extraction.md` (Task 8b's interfaces are used verbatim here).

## Global Constraints

- Exactly eight arms, T1 to T8, on every octopus, preview and still. Technology count never sets anatomy.
- Physics is cancelled. No videos: evidence is stills, numbers and tests; the owner checks motion live at a local URL.
- No tone mapping, `flat` canvas. Colours are sRGB hex in config.
- No new runtime dependency (spec 4): the router and the IndexedDB store are small platform modules.
- `src/platform/**` and `src/worlds/octoverse/**` import only engine contract exports, world bundles (read-only) and their own files; they never edit `src/engine/**` or another world's folder. `boundary.test.ts` gains `src/platform/**` with this rule.
- At most two live WebGL contexts at once anywhere in the platform (spec 2.4): the page instance plus one preview.
- Frame-rate floors (spec 2.4), median fps at tier low, 1536 x 1024, pixel ratio 1, production build, browser pane closed, back to back: landing intro 40; entrance 32; How It Works with one live card 36; profile with live hero 40; creator with live preview 36; each world through the platform at its own floor and within 3% of its `?world=` number.
- Colour targets: spec 2.1, CIE76 delta E 10 per sample, plus its global checks (peach face, blue crown, warm core, warm cups, indigo water).
- Copy that the spec fixes (titles, button labels, badges, footer, Publish text) is used verbatim.
- Every showcase profile and tile carries the "Showcase" badge; no fact is invented; missing links, locations and screenshots stay absent.
- No feeds, follows, comments, messaging, search, pricing, sign-in or custom domains.
- 44 px targets, visible focus, reading-order keyboard paths, reduced motion honoured, no horizontal scroll at 360, 390, 768, 1024 and 1536 px.
- Never edit, reset or restore the main checkout. No bare `git stash`. No push.
- The owner approves each milestone live before the next starts; commit per approved milestone. Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Model tiering: Opus for the host's look, face, poses and motion and the reef's light (Tasks 3, 5, 6, 11, 12); cheaper models for routes, pages, forms, storage and tests.

## Review Focus

1. **Back pressed during a world's entrance or during a route fade.** The visitor lands on the opening page; the world unmounts cleanly; no fade overlay, listener or context is stranded (Task 15, `back during entrance` e2e).
2. **A deep link with a bad or forbidden view** (`?view=techFocus`, `?view=x`, `/@veyra/nope`). A bad view opens the world's intro and the URL is replaced without it; an unknown project shows not found (Task 14, `parseRoute` tests; Task 15 e2e).
3. **IndexedDB unavailable or blocked** (private window, storage denied, quota full). The creator still works in memory, shows "Can't save in this browser", and never throws (Task 18, storage tests with a failing `indexedDB.open`).
4. **Rapid hover across cards or tiles, and touch plus mouse on one device.** Never more than one live preview; the last requested wins; no context or listener growth (Task 13, preview-slot tests and e2e).
5. **A draft with zero projects, or a project with zero technologies.** The preview still renders the octopus with nothing on its arms, and `/create/preview` opens the intro with an empty overview rather than failing (Task 18 `assembleBundle` tests; Task 20 e2e).
